# Login Form

A simple, modern login form built with HTML and styled using Tailwind CSS.

## Features

- Clean and responsive design
- Dark theme with gray and blue color scheme
- Email and password input fields
- Styled with Tailwind CSS utility classes
- Focus states with blue ring highlights
- Hover effects on the login button

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript (module-based)

## Structure

The project includes:
- `index.html` - Main HTML file containing the login form
- `src/main.js` - JavaScript module file
- `src/main.css` - CSS styles
- Tailwind CSS configuration files

## Usage

Simply open `index.html` in a web browser to view the login form. The form features:
- Email input field
- Password input field
- Submit button

## Styling

The form uses a dark theme with:
- Gray background (`bg-gray-900`)
- Card-style container with shadow (`bg-gray-700`)
- Blue accent color for interactive elements
- Responsive design that centers on the screen
